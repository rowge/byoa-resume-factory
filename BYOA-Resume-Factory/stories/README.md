# Stories

| File | Use |
|------|-----|
| `INBOX.md` | Dump first. Voice, half-memories, “wait I also…” |
| `STORY-BANK.md` | Locked catalog. Stable IDs. Resumes pull from here. |

1. Paste into the inbox. Messy is the point.
2. When it’s true enough, promote into the bank with a new ID, tags,
   one-liner, STAR if you have it.
3. Job packages **link IDs**. They do not copy a competing write-up.

IDs never change meaning. Personal / awkward stories use `S-P01` so they
are easy to keep off a resume and on a form.
