BYOA Resume Factory

What you need

An agent that can open a folder

Grok Build, Cursor, Claude Code, Codex, Windsurf — anything that reads and edits files on your machine. ChatGPT in a browser can help you draft, but it cannot run the factory. If you don’t have an agent, use Story Bank Resume Factory instead.

Windows, Mac, or Linux

Unzip, then open the folder that contains AGENTS.md. Windows “Extract All” sometimes creates an extra nested folder — go in one level if you don’t see that file.

Python 3.10+ to print PDFs

Talking, scoring jobs, and filling YAML work without it. The resume and cover letter files are built by a small script. That script needs Python 3.10 or newer.

On Windows, install from python.org and check “Add python.exe to PATH.” The Microsoft Store button that says Python but only opens the Store does not count. First time, your agent will also run pip install for two libraries (needs the network once).

No Python → no PDFs. The kit will not invent a resume file. You can still do the hunt in the folder and print later.
