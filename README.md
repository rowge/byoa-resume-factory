# BYOA Resume Factory

Free kit, and the page at https://byoaresumefactory.com

`BYOA-Resume-Factory/` is the folder. Unzip it, or point an agent at it, and talk. The buyer's license is `BYOA-Resume-Factory/LICENSE.txt`.

`site/` is the store. From this folder:

```bash
./site/deploy.sh
```

That rebuilds the zip and ships the page. Set `CLOUDFLARE_ACCOUNT_ID` first. The API token stays in `~/.config/cloudflare/api_token`.

No folder and no Python: [Story Bank Resume Factory](https://x.ai/bot/ZvGhPg4HFYSG61rMsAIAy) on Grok Bot.
